# Adarsh S — Portfolio

Next.js 16, React 19, Tailwind 4, Playwright.

```bash
npm install
npm run dev        # local dev
npm run build      # production build
npm run typecheck && npm run lint
npm test           # Playwright e2e (needs a build first)
```

Project data lives in `src/data/projects.ts`, site details in `src/data/site.ts`.
